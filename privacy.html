Privacy Policy

This policy explains the TikTok-related information processed by the current local SocialFlow workflow and the data practices of this static website.

Effective November 3, 2026Version 1.0

On this page

1. Scope 2. This website 3. Information 4. How it is used 5. How data moves 6. Storage & retention 7. Disclosures 8. Your choices 9. Security 10. Children 11. Changes 12. Contact

1Scope

This Privacy Policy covers the public SocialFlow AI Publisher website and the TikTok-related workflow described for the current locally operated SocialFlow application. It does not replace TikTok's own privacy notice or describe TikTok's independent processing.

The application is in private testing. If its providers, data flows, audience, or production features change, this policy must be updated before those changes are offered for public use.

2This static website

We do not add analytics, advertising scripts, account forms, or first-party tracking cookies to this website. The site is served through GitHub Pages. GitHub may process technical request information, such as IP address, browser details, and access logs, under the GitHub General Privacy Statement.

This website does not connect to your TikTok account and cannot access application credentials or account content.

3Information processed by the TikTok workflow

The current implementation may process the following information when an authorized operator uses the local application:

Authorization data

OAuth authorization code, security state, access token, refresh token, expiration information, and the redirect address used for the connection.

Basic TikTok account data

Fields TikTok returns with the user's authorization, such as a unique account identifier, display name, or avatar.

Creator and posting options

Information TikTok returns about available creator posting capabilities and privacy or interaction choices.

Selected content

Video, caption, and posting choices selected by the operator if an upload or publishing feature is enabled and the operator initiates it.

SocialFlow requests the TikTok scopes user.info.basic, video.upload, and video.publish for the reviewed workflow. TikTok shows requested permissions during authorization.

4How information is used

The described TikTok data is used to:

  • start and complete the user-authorized OAuth connection;
  • validate the authorization response and reduce replay or cross-brand errors;
  • identify the connected account and display authorized creator posting options;
  • refresh access when TikTok permits it;
  • send content to TikTok only when the operator initiates a supported upload or publish action; and
  • diagnose connection, security, or publishing errors in the local environment.

5How TikTok data moves

The operator begins authorization in a browser on TikTok. TikTok returns an authorization result to the configured callback. The local application exchanges an authorized code with TikTok's API, stores the resulting credentials locally, and uses them for the scopes approved by the user.

When an operator initiates an upload or publish action, the selected content and posting choices are transmitted to TikTok. It would therefore be inaccurate to say that all TikTok-related data always remains on the device.

6Local storage and retention

TikTok credentials are stored in a TikTok-specific encrypted vault on the operator's device, with local encryption key material. TikTok and Meta credentials are held in separate vaults. OAuth state records are designed to expire and be used only once.

Access and refresh tokens remain in local storage until they expire, are replaced, or are removed from the local environment. Revoking SocialFlow in TikTok stops future authorized access but may not by itself erase existing local files. Selected content remains subject to the local files and settings controlled by the operator and, once transmitted, to TikTok's own retention practices.

7When information is disclosed

TikTok-related information is sent to TikTok as needed to authenticate, read authorized account capabilities, and complete an action the operator initiates. GitHub processes technical request data to deliver this public website.

This policy does not claim that an optional AI provider or other integration is active. Before any feature sends prompts, media, or account information to an additional provider in production, the provider and relevant data practices must be confirmed and this policy updated where required.

Information may also be preserved or disclosed when required by applicable law, or when reasonably necessary to protect users, accounts, the Service, or others from fraud, abuse, or security threats.

8Your choices and controls

  • Do not connect: You may decline TikTok's authorization request.
  • Choose the action: An upload or publish flow begins only after an operator selects it.
  • Revoke access: You may revoke SocialFlow's access from TikTok's account settings.
  • Remove local data: The operator may remove SocialFlow's local application data and encrypted credential vault from the device. Back up anything that must be retained before deletion.
  • Ask a question: Use the contact route below for an access, correction, or deletion question. Do not place personal information in a public issue.

Your legal privacy rights may differ by location. We will evaluate a verified request under the law that applies to it.

9Security

The described safeguards include encrypted local credential storage, separate platform vaults, expiring single-use OAuth state, and brand-bound state validation. The public legal repository is kept separate from the private application and is not intended to contain credentials or account content.

No system is completely secure. Protect the operating device, restrict local access, keep software current, and revoke platform authorization if you believe a credential or device has been compromised.

10Children

SocialFlow is not directed to children. It is intended for an authorized operator who is eligible to manage the connected platform account. Do not use the Service to process a child's personal information without all permissions and protections required by law and platform rules.

11Changes to this policy

We may update this policy when the Service, its integrations, or legal requirements change. The current version will be posted here with a revised effective date.

12Contact

Contact the SocialFlow operator through the repository owner profile. You may open a minimal privacy contact request asking for a private follow-up. Do not include personal data, TikTok identifiers, credentials, or confidential information in a public GitHub issue.
