The workflow

From connection to an intentional action.

SocialFlow is designed for an operator who controls the connected account. TikTok access starts with OAuth, and an upload or publish action starts only after the operator chooses it.

  1. 01

    Connect the right account

    TikTok presents the permissions requested by SocialFlow. The user decides whether to authorize them and may revoke access through TikTok.

  2. 02

    Confirm posting options

    The local app reads the authorized account identity and creator posting capabilities so the operator can review the destination and available choices.

  3. 03

    Prepare and review

    The operator selects content and checks any caption, audience, or platform options before an upload or publish request is sent.

  4. 04

    Initiate the action

    When production publishing is enabled, the operator may choose to send content to TikTok as a draft or initiate a direct post, subject to TikTok's controls.

TikTok permissions

Only the scopes needed for the reviewed workflow.

Permission names are shown as they appear in TikTok's developer platform. Authorization is controlled by the TikTok user.

user.info.basic

Identify the connected account

Used to retrieve basic profile fields that TikTok returns with the user's authorization, such as an account identifier, display name, or avatar.

video.upload

Send content as a draft

Used when the operator explicitly chooses an upload flow that sends selected content to TikTok for completion there.

video.publish

Initiate a direct post

Used only when the operator explicitly chooses a direct publishing action and the feature is approved and enabled.

Data & safety

Public information here. Private credentials there.

This GitHub Pages site is deliberately separate from the private SocialFlow application. It contains product information and legal notices, not application code, credentials, access tokens, or account content.

◇

Encrypted local credential vault

TikTok OAuth credentials are stored in an encrypted vault on the operator's device. Encryption key material is also held locally.

↯

Short-lived OAuth state

The authorization flow uses expiring, single-use state validation to help prevent replay and cross-brand mix-ups.

∥

Platform separation

TikTok and Meta credentials are kept in different vaults. This public repository contains neither.

○

No site analytics

This static site adds no analytics, advertising scripts, account forms, or first-party tracking cookies.

User control

The connected user stays in charge.

  • Review TikTok's permission screen before connecting.
  • Choose the content and posting action.
  • Revoke SocialFlow access from TikTok's settings.
  • Stop local use without using this public website.
