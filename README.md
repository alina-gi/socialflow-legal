# SocialFlow AI Publisher — public site

This repository contains only the static public website and legal notices for SocialFlow AI Publisher.

Published pages:

- Home: `https://alina-gi.github.io/socialflow-legal/`
- Terms: `https://alina-gi.github.io/socialflow-legal/terms.html`
- Privacy: `https://alina-gi.github.io/socialflow-legal/privacy.html`

The repository is intentionally separate from the private SocialFlow application. Do not commit application source, `.env` files, OAuth client secrets, access or refresh tokens, user content, local vaults, encryption keys, callback state files, logs, or screenshots containing account data.

## Publishing

GitHub Pages should publish from the `main` branch and repository root (`/`). The site has no build step and no external JavaScript dependencies.

## Before TikTok production review

Read [`REVIEW_CHECKLIST.md`](REVIEW_CHECKLIST.md). Legal text should be re-checked whenever the application's data flows, providers, requested scopes, intended audience, or production behavior changes.
